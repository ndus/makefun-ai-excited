# AI Excited

## What the image shows

A red fox leaps across a canyon, suspended above a river of swirling galaxies. Firelight catches its fur and traces a bright rim around its silhouette.

## How the entry works

`main.ts` streams the bundled `entry.png` into the output directory and verifies the copy by comparing SHA-256 hashes.

## How to run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
